​Multi-Ecosystem Packaging & Integration Engine
​Genix Gemini CLI is a multi-ecosystem packaging and integration engine designed by Eric Todd Sawyer to manage software bills of materials (SBOMs), cross-ecosystem dependencies, and enterprise automation workflows seamlessly.
​🛠️ GitHub Actions CI/CD Workflow
​The project automatically generates CycloneDX SBOMs across multiple package ecosystems (npm, maven, pypi, and go) on every push or pull request to the main or master branches.
